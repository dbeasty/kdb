# Entry points for the embeddable Go source bundle (docs/kdb-release-plan.md §2.2).
# One import path per line, relative to the module root (github.com/limidus/kdb/go).
# The bundle is the transitive closure of `go list -deps` over these, unioned across every
# GOOS/GOARCH in embedbundle's platform matrix. Comments and blank lines are ignored.

kdb/embed         # embedded runtime: open, put, commit, materialize
kdb/driver        # database/sql driver over that runtime
kdb/sql           # KDB-SQL parser, planner, executor
kdb/query/hybrid  # hybrid query engine
kdb/index         # index core
kdb/server        # native server engine (wire protocol, transport, peer sync) - a downstream
                  # project that imports kdb/server directly (e.g. to build its own server
                  # binary/image around it) needs this in the bundle too, not just the pure
                  # in-process kdb/embed surface above
