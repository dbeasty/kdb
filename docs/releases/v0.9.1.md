# v0.9.1

**The server code is identical to v0.9.0.** v0.9.0 published its container image (linux/amd64
and linux/arm64) and the `@limidus/kdb-client` tarball, but not its binaries, jars or Go source
bundle. The release job that builds them checks that the embeddable Go bundle compiles and passes
its own tests on its own, and the bundle was missing a test-only helper package. The bundler was
wrong, not the server (#314), so this release republishes the same code with every artifact.

Everything in `docs/releases/v0.9.0.md` applies, including its Upgrading section: the
`@limidus/kdb-client` rename, matching client and server minor versions, `--control-open`, and
rolling back to v0.8.2.

## What changed since v0.9.0

**The Go source bundle includes test-only helper packages (#314, build tooling only).** #304 added
`kdb/internal/testtime`, which only tests import, so the bundler left it out. It then skipped
every test file importing it, including two files whose helpers other tests use, and the bundle's
tests no longer compiled. The bundler now adds such a package when everything it needs is
already in the bundle.

## Upgrading

From v0.9.0: nothing to do if you run the container image or the 0.9.0 client tarball; they are
the same code. Use v0.9.1 for binaries, jars and the Go source bundle. `@limidus/kdb-client` 0.9.0
and 0.9.1 work with either server. From v0.8.x: see v0.9.0's notes.
